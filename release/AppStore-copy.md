## 中文名称与副标题

名称：牌阵师

副标题：五行五列，一步成阵

## 推广文本

在方寸棋盘中争一线之机。与山海棋手对弈，每天解一道残局，收集你的山海印章。

## 描述

以牌成阵，以阵会友。

牌阵师将扑克牌型与棋盘策略结合：在 5×5 棋盘上轮流落子，争夺行、列和对角线。牌型决定分数，棋子数量决定归属。多想一步，便有新的可能。

【问道对弈】
与策略棋手交锋，积累自己的段位与连胜。胜负由完整棋局决定，认负同样记录在战绩中。

【闲庭对弈】
选择入门或策略难度，按自己的节奏思考。每次落子自动保存，随时离开，随时续局。

【每日一题】
同日同题，一张手牌，五处落点。确认落子后结算，再通过复盘比较不同选择的得分。

【山海篆印】
完成棋局和旅程任务，积累灵玉，解锁并装备山海印章。收藏只改变外观，不影响对弈能力。

【棋局有迹】
查看阵线计分与棋局复盘，保留最近战绩，也可主动分享自己的战绩海报。

无需账号或网络。不含广告或内购。进度保存于当前设备；每日一题按 UTC 日期更新，即北京时间每天 8 点。

## 关键词

## 审核备注（可据实填写）

This is a fully playable offline strategy board game. No login, backend, purchases, ads, or account creation are required.

The user and a computer opponent place playing cards on a 5-by-5 board. A completed row, column, or main diagonal awards poker-pattern points to the side owning at least three cells. There is no betting, cash value, cash-out, random loot box, or real-money reward. The in-game currency is earned by play and spent only on cosmetic seals.

First launch includes a short interactive tutorial; it can be skipped or replayed from the profile page. The ranked single-player mode records resignations as losses. The daily puzzle allows one completed attempt per device per UTC date, and its result screen includes all five placement scores. Progress is saved on-device. Completed matches can be inspected from the result screen or recent history.

Privacy policy: Profile → Privacy Policy. Data deletion: Profile → Personal Settings → Clear All Local Progress (requires confirmation). The system share sheet opens only after the user requests sharing.
